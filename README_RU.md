# Как повторить эксперимент

Статья — `paper/manuscript_ru.docx`, читаемый исходник — `paper/manuscript_ru.md`. Эксперимент один: пять способов обработки просмотров, два временных среза, три seed. Полная методика, команды и ограничения — [README.md](README.md).

## Самый простой запуск

В Kaggle импортируйте `notebooks/KION_WatchFeedback_5methods_Kaggle.ipynb`, включите Internet и GPU и нажмите Run All. Ноутбук автономный: данные скачиваются с закреплённого адреса, контрольная сумма проверяется автоматически. Научные настройки менять не нужно. Подробности — `docs/KAGGLE_RU.md`.

В конце скачайте итоговый ZIP с таблицами и рекомендациями. Отдельно сохраните выходы Kaggle с папкой `runs` и весами: облегчённый ZIP не подходит для продолжения обучения. Оригинальное чистое обучение 30 моделей занимало около 2 ч 24 мин на одной T4, валидация — ещё около 25 мин. Это измерение конкретной сессии; подготовка, тест и интервалы добавляют время.

## Запуск без ноутбука

```bash
python -m pip install -r requirements.txt
python reproduce.py --output outputs/full
```

Для обучения требуется CUDA. Точная записанная среда — `reference_results/environment.json`; закреплённые прямые численные зависимости — `requirements-paper-cu128.txt`. Это не полный pip freeze. При новой среде получится новый хеш плана; смешивать её с незавершённой старой серией программа не позволит.

Повтор той же команды продолжает сохранённое обучение. Для переноса задайте `--resume-from /путь/к/папке/с/весами`. `--max-runs 5` ограничит сессию пятью новыми моделями; итоговый тест начнётся только после готовности всех 30.

Короткая техническая проверка на CPU:

```bash
python -m unittest discover -s tests -v
python reproduce.py --smoke --output outputs/cpu-smoke
```

Первый запуск не скачивает KION; второй использует исходный KION, но только 80 пользователей на срез и два шага. Его результаты не являются результатами статьи.

## Проверка без обучения

```bash
python analysis/check_release.py
python analysis/plot_results.py --results-dir reference_results --output-dir outputs/figures
```

Для независимого пересчёта вашего полного результата нужны итоговый ZIP и официальный KION:

```bash
python analysis/verify_results.py --archive outputs/full_results.zip --data-archive /путь/data_en.zip --output-dir outputs/audit
```

Эта проверка заново строит обучающие окна и будущие цели, пересчитывает метрики по рекомендациям и все 32 интервала; GPU и загрузка весов не нужны. В репозитории есть агрегаты исходного опыта и отчёт его проверки; пользовательские рекомендации, исходные данные и веса не включены.

## Дополнительный анализ зрителей и фильмов

Полный разбор — `reference_results/posthoc/POSTHOC_ANALYSIS_RU.md`. Три разбиения зрителей используют только прошлую историю; фильмы разделены по обучающей частоте. Новый анализ исследовательский, с описательными 95%-интервалами без поправки на множественные сравнения. Он не меняет исходные четыре основных сравнения и не обучает новые модели.

```bash
python analysis/plot_posthoc.py --results-dir reference_results/posthoc --output-dir outputs/posthoc_figures
python analysis/posthoc_analysis.py --archive outputs/full_results.zip --data-archive /путь/data_en.zip --output-dir outputs/posthoc
python analysis/write_posthoc_report.py --results-dir outputs/posthoc
```

Первая команда строит рисунки по поставляемым агрегатам без исходных пользовательских данных. Вторая полностью пересчитывает дополнительный анализ по собственному полному архиву результатов и KION. Третья готовит подробный разбор; его интерпретации и пример отдельного фильма относятся к исходному опыту и требуют проверки при новых результатах. Пользовательские строки и ID в публичный пакет не входят.
