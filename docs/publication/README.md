Основная рукопись — 8 страниц; онлайн-приложение — 13 страниц и не входит в эту нумерацию. Это рукопись, не свидетельство принятия или публикации журналом. [SHA256SUMS.txt](<SHA256SUMS.txt>) содержит контрольные суммы остальных семи файлов каталога, включая вложенный CSV.

Для чтения полного комплекта распакуйте ZIP, сохраняя структуру каталогов. Приложение находится рядом с папкой supplementary-data; упомянутые в нём локальные относительные пути отсчитываются от этой папки. Ссылки внутри приложения ведут к закреплённой версии научного репозитория. Для автономного чтения используйте соответствующие файлы из архива; подключение к сети для чтения сохранённых таблиц и рисунков не требуется.

Авторские планы и отчёты сохранены как исторические научные материалы. Их сведения о выполненных ранее проверках не означают нового обучения, инференса или bootstrap при подготовке данного комплекта. Первичные данные и условия их использования описаны в DATA_SOURCES.md внутри supplementary-data; код и инструкции доступны в закреплённом репозитории.
